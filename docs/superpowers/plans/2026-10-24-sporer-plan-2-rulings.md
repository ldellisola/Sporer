# Sporer Plan 2 — rulings, deferred minors and checks before release

Decisions made on the owner's behalf while building Plan 2 (the web app and its server endpoints; built task by task with a separate review of each task), each with what it costs if wrong. Generated from the build ledger on 2026-10-26.

## Check on the iPhone before the first `v*` tag

These cannot be verified in the build container (no WebKit, no real GPU, no access to OpenFreeMap):

- City labels are in English in both the light (`liberty`) and the dark style.
- The range date fields do not zoom the page on focus; double-tap does not zoom the bar or the sheet.
- The light-mode status bar (white text under `black-translucent`) is readable over the scrim.
- Landscape: map buttons and the OpenStreetMap credit clear the Dynamic Island side.
- "Map unavailable" → Retry really re-fetches the MapLibre chunk on WebKit (some engines cache a failed module fetch).
- Performance on real data: spec §8 targets were measured only on synthetic data with software WebGL (see `2026-10-24-sporer-plan-2-perf.md`).
